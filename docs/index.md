# RTM — Requirement Traceability Matrix

A web application for managing and tracking the full traceability chain from business requirements through technical requirements to test cases, with capacity planning and role-based access control.

## Goal

Provide a single source of truth where business requirements are defined, linked to their technical components (technical requirements, test cases, use cases), tracked for coverage, and planned for capacity — all in one place.
