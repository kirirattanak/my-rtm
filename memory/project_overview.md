A Requirement Traceability Matrix web app. Single source of truth for business requirements → technical requirements → test cases → capacity planning.

**Tech stack:** Laravel 11, Vue 3, Inertia.js, Tailwind CSS, shadcn/ui, Vite. MySQL/PostgreSQL.

**Primary color:** Dark red (`#8b1a1a` / `primary-800` in Tailwind config).

**Milestone status:**
- Milestone 1 (Foundation & Auth) — complete
- Milestones 2–7 — pending

**Why:** User wants a single source of truth for managing and tracing business requirements through technical components to test cases, with capacity planning.

**How to apply:** Keep new features scoped to the active milestone. Don't add features from later milestones early. Follow the roles/permissions matrix in docs/roles-permissions.md.
